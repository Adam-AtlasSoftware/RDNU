# Radeon Decoupled Neural Upscaler (RDNU)

An open neural temporal upscaler for AMD RDNA2 and RDNA3 on DirectX 12, in the class of FSR 4
and DLSS. It takes jittered low-resolution colour, depth and motion vectors and returns
anti-aliased high-resolution frames. The network is
[Arm Neural Super Sampling](https://huggingface.co/Arm/neural-super-sampling) (148K parameters,
INT8), chosen in [docs/Model_Candidates.md](docs/Model_Candidates.md). RDNU runs it on DP4a
(RDNA2) and wave-matrix (RDNA3) kernels behind the FidelityFX API. It drops into games as FSR
3.1's DLL, as FidelityFX SDK 2's upscaler DLL, or through OptiScaler.

## Status

Built and verified without AMD hardware, on Mesa lavapipe through vkd3d-proton, and on the Windows
binaries under Wine:

- The INT8 network matches the exporter's integer golden bit for bit, also at a smaller frame size in the same arena.
- Arm's NSS passes, ported to HLSL, match Arm's GLSL on real frames.
- The FidelityFX API provider covers exposure (texture, auto, preExposure), sharpening,
  jittered and display-resolution motion vectors, and size changes. It forwards frame generation
  and other versions to AMD's DLL. AMD's signed SDK 2 loader drives it with results identical to
  the direct path.
- On a Bistro crop at 2×, RDNU scores 29.9 dB PSNR against 29.4 dB for AMD's FSR 3.1.5 on the same
  inputs. That is 16 frames at 248×232, too small to generalise.

Next, on a 7900 XTX and a 6800 XT: timings (`runtime/tools/eval/bench.md`), the FSR sample, games,
and comparison with FSR 4.1. Retraining on more data is scripted
([ml/retrain](ml/retrain/README.md)) and decided after that
([docs/NSS_Quality_Plan.md](docs/NSS_Quality_Plan.md)).

## Layout

```
runtime/
├── src/engine/        network planner (platform-free) and D3D12 recorder
├── src/backend_dx12/  D3D12 backend for Arm's NSS component
├── src/provider/      the FidelityFX API DLL, FSR-to-NSS mapping, captures
├── shaders/net/       INT8 conv kernels (DP4a, wave matrix)
├── shaders/nss/       Arm's passes in HLSL (generated by tools/port_nss_shaders.py), RCAS, exposure, motion
├── tests/             core, Vulkan (against Arm's GLSL) and D3D12 tests
├── tools/             export, goldens, rdnu_shaderc, eval/compare.py, setup and Wine scripts
├── harness/           network timing, whole-upscale bench, reference engine
├── integration/       the FSR sample patch for the FidelityFX SDK fork
└── external/          FidelityFX SDK fork, Arm neural graphics SDK, DirectX-Headers
ml/retrain/            fine-tune, QAT, export and install a retrained model
ml/                    model gym, capture plugin, weights, datasets (submodules)
RDG/, scripts/         the earlier RDG model, kept as a baseline
```

The leaked FSR 4 source (github.com/lhl/fsr4-rdna3-optimization) is a reference for HLSL structure
and INT8 conventions only. Its licence is contested, so none of its code or weights is copied here,
and it is not a training source.
